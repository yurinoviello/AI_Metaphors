## Rules of programming

1. Always use comments to explain the next line of the code:

\`\`\`
# Create a sphere of color BLUE for the Earth
earth = Sphere(radius=1, checkerboard_colors=[BLUE_D, BLUE_E])
\`\`\`

This is needed to understand what you meant to do.

2. Always include the classes implementation signature and code in your output, otherwise it will raise an error.
   You have to explicitly include the code of the elements class implementation.

3. Check accurately the code included in the classes json, feel free to modify it if it does not look correct to you.

4. Follow the instructions contained in the description; they may be very useful.

5. If you need to remove all the elements from the scene, remember to use this simple method:
    ``` self.play(*[FadeOut(mob)for mob in self.mobjects])```
    Since All mobjects in the screen are saved in self.mobjects

6. When you use element with an SVGMobject ALWAYS writes the exact full path indicated in the description; otherwise it will raise and exception.

7. ALWAYS make sure that the Scene class is called GenScene.

8. The text must be positioned always on top. It is a good rule to have no more than three texts at the same time, so be sure to clean the scene before positioning new text.

9. Start with this code that already defines a lot of useful functions (remember to include it in your generated code):
```
import manimpango
manimpango.register_font('ai_metaphors/resources/JetBrainsSans-Regular.ttf')
from manim import *

class GenScene(Scene):
    def remove_everything(self: Scene):
        """
        :param self: A Scene object containing all the mobjects to be removed.
        :return: None
        """
        if len(self.mobjects) > 0:
            self.play(*[FadeOut(mob) for mob in self.mobjects])
        return


    def start_end_scene(self: Scene, title: str):
        """
        :param seld: The Scene object where the animations and visual elements are rendered.
        :type seld: Scene
        :param title: The title text to be displayed at the start/end of the scene.
        :type title: str
        :return: None. Performs visual operations in the given scene and then exits.
        :rtype: None
        """
        # Clean the scene
        self.remove_everything()

        # Define the title and the logo
        title = Text(
            title,
            color=WHITE,
            font_size=40,
        )
        logo = ImageMobject("ai_metaphors/resources/JetBrains-logo.png").scale(0.3).next_to(title, DOWN)

        # Display the title and the logo
        self.play(Write(title))
        self.play(FadeIn(logo))

        # Leave them on the screen for 2 seconds
        self.wait(2)

        # Remove everything from the scene
        self.remove_everything()

        return
    def describe_scene(self: Scene, description: str):
        """
        :param self: The Scene object where animations and transitions will be played.
        :param description: A string representing the description text to display on the scene.
        :return: None
        """
        description = Text(
            description,
            color=WHITE,
            font_size=24,
        ).to_edge(UP)

        self.play(Write(description))

        self.wait(2)

        self.play(FadeOut(description))
        return


    def construct(self):
        self.start_end_scene("ONELINEMETAPHOR")

        # TODO

        self.start_end_scene("Thanks for watching!")
```
