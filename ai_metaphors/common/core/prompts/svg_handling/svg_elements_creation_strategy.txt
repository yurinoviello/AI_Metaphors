
2. Fallback — use Manim primitive graphics
   As a skilled Manim animator, when no suitable SVG file exists, you must create graphics using Manim's built-in primitive objects instead of generating SVG code.

   **Implementation Guidelines:**
   • Combine multiple primitive shapes to create complex illustrations
   • Use VGroup() to group related elements together
   • Position elements precisely using .move_to(), .shift(), .next_to()
   • Scale appropriately with .scale() to fit the scene
   • Prefer Manim primitives over any SVG creation for static illustrations
   • Only use animations when specifically needed for the story

   **Key Principle**: Strongly prefer creating illustrations with Manim primitive objects rather than generating SVG code. This ensures better integration with animations and maintains consistent styling across the scene.
